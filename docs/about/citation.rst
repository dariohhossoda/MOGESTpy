Citing MOGESTpy
===============

MOGESTpy is archived on Zenodo. If you use it in your research, please cite
it:

.. code-block:: bibtex

   @software{mogestpy,
     author = {Dario Hachisu Hossoda},
     title = {MOGESTpy},
     year = {2026},
     url = {https://doi.org/10.5281/zenodo.12215704},
     doi = {10.5281/zenodo.12215704}
   }

The DOI `10.5281/zenodo.12215704 <https://doi.org/10.5281/zenodo.12215704>`_
refers to all versions and resolves to the latest one. Each release also has
its own DOI, listed on the Zenodo page; cite that one to point to the exact
version used in a study, and report the version printed by
``mogestpy.__version__``.

The models themselves should be cited from their original publications, given
in the :doc:`user guide </user_guide/index>` pages.
