Examples
========

Complete scripts that run with the data shipped in the repository
(``docs/examples/data``). Each page shows the code, its output and figures,
and can be downloaded as a Python script or a Jupyter notebook. To run a
downloaded example, place the ``data`` folder from the repository next to it.

The forcing data are 2123 days of precipitation and potential
evapotranspiration (mm/day) for the Biritiba basin, the series of the original
SMAP example notebook in ``Applications/``, with a drainage area of 70.2 km².
