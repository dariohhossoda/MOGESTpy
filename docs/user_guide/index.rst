User guide
==========

What each model represents, its equations and parameters, and how to use it.
For runnable scripts with data and plots, see the :doc:`/auto_examples/index`.

.. list-table::
   :header-rows: 1
   :widths: 30 70

   * - Page
     - Models
   * - :doc:`smap`
     - SMAP rainfall-runoff, daily (``SmapD``) and monthly (``SmapM``)
   * - :doc:`muskingum`
     - Muskingum flood routing, linear and non-linear
   * - :doc:`network`
     - Basin networks: SMAP per subcatchment with routing between them
   * - :doc:`hydrodynamic`
     - SIHQUAL and Saint-Venant hydrodynamics
   * - :doc:`quality`
     - Zero-dimensional reservoir model and build-up/washoff
